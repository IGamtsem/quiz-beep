# Quiz Beep

Кнопка BEEP для квизов: https://igamtsem.github.io/quiz-beep/

В режиме «1» на экране одна большая кнопка, сигнал даёт касание или Пробел. В режимах «2–4» у каждого игрока своя кнопка и свой тон; первое нажатие блокирует остальных до сброса и показывает время реакции. Клавиши игроков: 1–4 или A, L, Z, M; сброс на R или Пробел. В настройках выбираются звук, громкость и имена игроков.

Один файл `index.html` без зависимостей, звук генерируется через Web Audio.
