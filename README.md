# Quiz Beep

Кнопка BEEP для квизов: https://igamtsem.github.io/quiz-beep/

Одна большая кнопка, под ней выбор звука. Нажать можно пальцем, а на компьютере ещё Пробелом или Enter.

- Классика: бип, «неверно», «верно», звонок, гонг, свисток, сирена, барабанная дробь, «та-да» и другие.
- Мемы: эйрхорн, vine boom, грустный тромбон, «дун-дун-ДУУН», ба-дум-тсс, бонк, сверчки. Это синтезированные имитации, а не оригинальные записи.
- Мемные фразы: bruh, oof, wow, sheesh, «Внимание, вопрос!», «Это фиаско, братан» и другие. Их произносит голосовой синтез телефона, поэтому голос зависит от устройства.
- Свои звуки: можно загрузить MP3/WAV/M4A до 5 МБ. Файлы хранятся только в браузере, где их загрузили.
- «Случайный» каждый раз выбирает новый звук.

Один файл `index.html` без зависимостей.
